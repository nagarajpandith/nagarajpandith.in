title: 'Babel'
type: 'short'
updatedAt: 'Dec 20, 2024'
---

**Babel** is like a translator for JavaScript. You write modern ES6+ code, and Babel converts it to older JavaScript that all browsers understand.

Think of it as: _You speak Spanish, but your friend only understands English. Babel is your interpreter._

```js
// You write:
const hello = () => console.log('Hi');

// Babel converts to:
var hello = function () {
  console.log('Hi');
};
```
